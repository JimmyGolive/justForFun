# CoupleSpark 💑

> 讓感情保持溫度的夫妻互動小遊戲

CoupleSpark 是一款為伴侶設計的互動 App，透過遊戲化機制幫助夫妻保持親密感、促進日常溝通，並讓兩人透過有趣的方式表達彼此的需求與心意。

## 核心功能

| 功能 | 說明 |
|------|------|
| 💌 **傳送心動** | 一鍵傳送「心動訊號」，類似護士呼叫鈴的概念，讓你低調地傳達你的心意（溫柔相擁、浪漫約會、親密時光…） |
| 🔔 **回應心動** | 收到對方的心動訊號後，可以選擇「現在就好」、「預約時間」或「今天先休息」 |
| 🔥 **連續天數** | 追蹤兩人每天的互動連續天數，維持「火花不中斷」 |
| ✨ **火花積分** | 每次成功的互動都能累積積分，積分越高火花越旺 |
| 🎁 **獎勵兌換** | 用積分兌換約定好的浪漫獎勵（燭光晚餐、SPA 之夜、小旅行…） |
| 🏆 **成就系統** | 解鎖各種里程碑成就，為感情增添成就感 |
| 😊 **今日狀態** | 每天記錄自己的心情與狀態，讓對方更了解你 |

## 設計理念

現代夫妻常因工作疲勞、生活壓力、荷爾蒙變化等因素，導致親密互動減少。
CoupleSpark 透過：

1. **降低開口的門檻** — 不需要尷尬地直接表達，用有趣的「心動訊號」傳遞心意
2. **尊重雙方節奏** — 接收方可以選擇「現在」或「預約時間」，不強迫
3. **遊戲化激勵** — 積分、連續天數、成就等機制讓維持感情變得有趣
4. **正向回饋循環** — 積累獎勵讓兩人共同期待、共同努力

## 快速開始

```bash
cd couple-spark
npm install
npm start
```

開啟 [http://localhost:3000](http://localhost:3000) 即可使用。

## 技術架構

- **框架**：React 19 (Create React App)
- **狀態管理**：React Context + useReducer
- **資料持久化**：localStorage
- **樣式**：原生 CSS（深色玻璃擬態風格）

## 開發指令

```bash
npm start      # 開發模式
npm test       # 執行測試
npm run build  # 建置生產版本
```
